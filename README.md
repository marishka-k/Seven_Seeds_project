# Seven Seeds — кулинарный мастер-класс в Москве

Учебный проект для портфолио: одностраничный лендинг по собственному макету.
Мастер-класс вымышленный, регистрация никуда не отправляется.

**Сайт:** https://marishka-k.github.io/Seven_Seeds_project/

## Что на странице

- шапка с якорным меню (активный пункт подсвечивается при прокрутке), на мобильной — бургер-меню;
- первый экран: дата, описание, кнопка «Зарегистрироваться»;
- «Меню» — три блюда; на узких экранах — слайдер с точками;
- «Что интересного ?» — четыре карточки, текст обрезается многоточием и раскрывается по наведению или клику;
- «Ведущая мастер-класса» — фото и факты;
- «Ждём вас на мастер-классе» — дата, адрес, стоимость;
- окно регистрации: имя, телефон, e-mail, согласие, проверка полей; отправка — демо.

## Стек

- Vite 5, React 18 (без роутера и UI-библиотек);
- CSS Modules, внутри модулей — БЭМ; глобально только `src/styles/global.css` с токенами;
- шрифт Montserrat (Google Fonts);
- деплой на GitHub Pages через `gh-pages`.

## Запуск

```bash
npm install
npm run dev       # локально: http://localhost:5178/Seven_Seeds_project/
npm run build     # сборка в dist/
npm run deploy    # сборка и публикация на GitHub Pages
```

## Адаптив

| Версия    | Ширина экрана | Макет  | Особенности |
|-----------|---------------|--------|-------------|
| Мобильная | до 599 px     | 375    | слайдеры с точками, бургер-меню, без фото ведущей |
| Мобильная | 600–1023 px   | 375    | карточки сеткой на всю ширину (блюда — 3, «интересное» — 2 колонки) |
| Лаптоп    | 1024–1439 px  | 1024   | меню в шапке, сетки 3 и 4 колонки, фото ведущей |
| Десктоп   | от 1440 px    | 1440   | шире 1440 контент и фоновые фото по центру, края фото растворяются в фоне |

Размеры задаются токенами в `global.css` и переключаются медиазапросами, без `clamp()`.

## Структура

```
public/images/        фото и фоны (webp), логотип, иконки
src/
  components/         блоки страницы и переиспользуемые компоненты:
                      Header, MobileMenu, Logo, Hero, Backdrop, Menu, DishCard, Dots,
                      Features, FeatureCard, Note, Host, FactCard, Final, Footer,
                      Button, SectionTitle, Modal, RegistrationForm, FormField, Checkbox
  data/               тексты: меню, блюда, «интересное», ведущая, данные мероприятия
  hooks/              useScrollLock, useActiveSection, useSlider
  utils/              asset (пути с учётом base), cx, validate
  styles/global.css   токены, сброс стилей
```
